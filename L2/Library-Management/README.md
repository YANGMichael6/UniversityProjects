# Library Management with Linked-Lists and Hash Table

## Description
In this C project (GCC compiler), the goal is to compare two different ways to implement a Library with multiple functions to manage it (like register x-lines of a text file, erase it, search...). You can use the makefile for both Library to compile directly.
- The first way is by using simple linked-lists structure.
- The second way is to implement a hash table, with a hash function and linked-lists again.
The thing is to observe that the Library implemented with a hash table is way more efficient, due to its average-case complexity in O(1) for the search function for instance.
